Ann Arbor flavor notice — neither asset pack contains real Ann Arbor artwork. Every landmark here is low-fi parody signage: a generic building sprite plus a painted-on text label (MICHIGAN STADIUM, THE DIAG, BURTON TOWER …). No real logos, no exact reproductions, no new pixel art invented to imitate a landmark.

Audio — no audio files anywhere: the chiptune music and every sound effect are generated live in JavaScript with the Web Audio API (oscillators + gain envelopes).
