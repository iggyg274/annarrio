Ann Arbor Platformer: Model Comparison

Below you will find several versions of the same video game, each created by a different AI model. Three frontier models (Sonnet, Opus, and Fable) were used as comparison (Opus is probably the best). The rest of the versions were built by local models on local hardware. Qwen3.8-Flash and Deepseek(s) are very good. You will see notable degradation with the smaller models.

All models were given the same Graphics template to work with, some did a better job than others (and Qwen3.8 27B decided to not use the graphics at all). All music was generated on the fly by the models

Each version was built from the same prompt (GAME.txt).
Information about Ann Arbor landmarks was not given -models figured that out themselves
